# Blank chat workspace toolbar

I restored project and worktree selection above the ordinary blank chat composer. The toolbar shows a Mousse-themed floating project picker (including No project and Open project), This computer, and a branch-icon Worktree toggle with the same active styling as the composer speed toggle. It appears for an empty hidden draft or the initial composer with no selected thread, and disappears after the chat starts. Agent DM and Group composers keep their separate creation flow.

I persist the workspace choice with each draft in its profile-local workspace state. Worktree starts off, requires a selected project, and uses the existing thread worktree opt-in and provisioning path. The first send waits for thread creation or the existing draft's worktree update before dispatching the prompt. Changing the project creates a new hidden draft on first send rather than moving an existing thread's storage. I transfer its staged text, references, browser attachments, files, and voice notes so selection failures leave the prompt recoverable.

I keep the current device fixed; remote execution remains deferred. The toolbar applies on all desktop platforms and adds no Linux window behavior.

I verified 18 focused thread creation, draft selection, and worktree protocol tests. `scripts/check-composer-workspace.mjs` mounts the real composer in Chromium with mocked service boundaries and checks project selection, worktree options before send, changing projects, navigation while creation is pending, failed worktree/selection recovery, draft persistence and profile isolation, and narrow layouts. I also checked the Black Sphere Plus toolbar border, project menu keyboard navigation/focus restoration and outside-click dismissal, selected-project checkmarks, portal placement, and Worktree pressed/disabled states. Its platform checks cover the shared renderer under Linux, Windows, and macOS flags. I also checked the renderer types, focused lint, and GUI production build; native worktree protocol coverage comes from `tests/threadWorktreeToggle.test.ts`.
