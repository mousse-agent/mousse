# Agents destination and guarded navigation

`MainViewPanel` mounts `AgentsWorkspace` at the existing Agents destination. Its two subtabs open the Agent Definitions workspace and workflow library/canvas. Both clients use `window.mousse.platformRequest`; catalogs come from profile-bound settings/integration/definition reads. Opening the library does not execute MCP servers. The explicit Refresh tools action connects enabled configured servers to read their tool lists. Agent run terminals remain available through the library's active-agents disclosure.

The workspace is kept mounted across main-area view changes so programmatic document/terminal navigation does not discard an editor. Inactive editor/orb/canvas activity receives the existing `active` signal. A dirty hidden agent editor can reveal the Agents pane before asking for a profile navigation decision. Workflow guards are registered with the same per-window navigation registry. Source parse errors count as unsaved workflow edits; confirmed discard restores the baseline manifest/source/history before a kept-mounted editor is hidden. Agent/Workflow subtab buttons support arrow/Home/End keyboard navigation through the guard.

The root navigation registry coalesces concurrent requests, keeps navigation cancelled when an editor declines or fails, and does not reuse a decision for a newly registered editor. Profile switching and main tab buttons consult it. The Agent Editor uses its existing discard/stay dialog; a separate hidden Electron fixture proves the profile stays unchanged while the dialog is pending and the unsaved name remains after cancellation.

Verification: full node/web typecheck passed; 31 Agent Editor and 33 workflow editor hidden Electron checks passed after these component changes. The fixture runners now use separate Vite dependency caches and select an available loopback port, avoiding the previous shared port/cache collision during parallel workgroup checks. These are editor/component checks, not a full production route qualification.
